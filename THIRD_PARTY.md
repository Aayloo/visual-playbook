# Third-party code and assets

This repository mostly **links** to other people's work, which needs no licence handling.
This file exists for the cases where code is actually copied into a project.

## Before copying anything

| Project | Licence | What to check |
| --- | --- | --- |
| GSAP | GreenSock standard "no charge" licence | Free for most uses, but commercial terms differ for resale and for some plugins. Read the current terms. |
| Highcharts | Commercial / proprietary | Requires a licence for commercial use. Not free for internal business software. |
| fullPage.js | GPL-3.0 | Copyleft. Fine for open source; a commercial licence is needed for closed products. |
| Tremor | Apache-2.0 (check current repo) | The licence has changed between versions; confirm against the version you install. |
| Aceternity UI | Commercial product | Not open source. Copying component code is the product; check what your licence permits. |
| Plotly.js | MIT | Free. |
| ECharts, D3, three.js, Lenis, Motion | MIT / ISC / Apache-2.0 | Free, keep the attribution. |

Entries in `data/cases.json` whose licence GitHub reports as `NOASSERTION` (Superset forks, some dashboards,
OpenBB, Metabase) need the `LICENSE` file in the repository read directly before use.

## Images and recordings

Screenshots of other people's products are fine as internal reference. They are **not** fine in anything
published or shared outward. When in doubt, link instead of copying.
